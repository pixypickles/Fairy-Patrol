# Fairy Guardian Prototype v2.1

ブラウザで `index.html` を開いて遊べる、縦型・見下ろし型の護衛シューティング試作です。

## v2.1 の変更

- 妖精、ヒヨコ、敵、魔法弾など動くものに太い黒い輪郭を追加
- エアーブラスト着弾時に円形の風リングと粒子が炸裂
- ウォーターボール着弾時に水しぶきリングと水滴が炸裂
- 双葉へ水を当てると、ツルと葉が約0.6秒で伸びて緑の橋になるアニメーションを追加
- 橋完成時にキラキラ演出を追加

## 操作

- 円形スティック: 8方向移動
- 風・上: 前方エアーブラスト
- 風・下: 近距離エアーブラスト
- 水・上: 前方ウォーターボール
- 水・下: 真下ウォーターボール

PCでは矢印キー、A/B/C/Dキーでも操作できます。
