# Fairy Guardian v3.7.3

## 変更内容
- 共通草原で条件達成後、すぐ選択画面へ切り替わらず、約6.5秒の薄暗い分かれ道を歩く演出を追加
- 分かれ道の終点で「花の多い草原／音の洞くつ／カエルたちの湿地」を選択
- 選択後も約4.6秒の専用道を進み、背景色が目的地の雰囲気へ徐々に変化
- 各ルートで+5000点達成後、約5.5秒の帰り道を通って共通草原へ戻る
- 遷移中は敵や重いギミックを停止し、妖精とヒヨコは歩き続ける
- スコアと距離は維持
