# Fairy Guardian Prototype

スマホブラウザ向けの縦長・完全見下ろし型護衛シューティング試作です。

## 操作

- 円形方向キー：妖精を上下左右へ移動（斜め入力にも対応）
- A：前方3方向へウィンドカッター
- B：前方斜め下へエアーブラスト。地面で破裂し、地上の敵や小枝を吹き飛ばす
- C：真下へウォーターボム。植物を育て、穴に植物の橋をかける
- D：ヒヨコへフェアリーシールド

PCでは矢印キーと A/B/C/D キーでも操作できます。

## 起動

`index.html` をブラウザで開いてください。GitHub Pagesにもそのまま配置できます。
