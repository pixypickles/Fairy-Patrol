# Fairy Guardian Prototype

スマホブラウザ向けの、見下ろし型・護衛シューティング試作です。

## 起動

`index.html` をブラウザで開いてください。GitHub Pagesへそのまま配置できます。

## 操作

- 画面内を指でなぞる：妖精を高速移動
- A：ウィンドカッター（上空の鳥）
- B：エアーブラスト（地上の敵、小枝の束）
- C：ウォーターボム（地上の敵、芽、穴に植物の橋）
- D：フェアリーシールド
