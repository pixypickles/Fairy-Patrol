# Fairy Guardian Prototype

スマートフォン向け縦スクロール護衛シューティングのブラウザ試作です。

## 遊び方

- 画面左側をドラッグ：妖精を高速移動
- A：ウィンドカッター（前方攻撃）
- B：エアーブラスト（斜め下。敵や小枝を吹き飛ばす）
- C：ウォーターボム（真下。敵を追い払い、植物を成長させる）
- D：フェアリーシールド（ヒヨコを短時間保護）

敵を倒す表現は使わず、魔法が当たると画面外へ逃げていきます。

## 起動

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーを使う場合：

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## GitHub Pages

1. このフォルダの中身をGitHubリポジトリへ追加
2. リポジトリの Settings → Pages
3. `Deploy from a branch` を選択
4. `main` / `root` を指定
