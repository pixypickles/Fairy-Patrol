# Fairy Guardian Prototype — Top-down Portrait Edition

スマホブラウザ向けの縦長・見下ろし型護衛シューティング試作です。

## 今回の画面仕様

- プレイ画面は縦長で、一般的な縦スクロールシューティング風
- カメラは地面を真上から見下ろす視点
- 空、地平線、遠景は表示しない
- 草地と土の道が下方向へ流れて見える
- ヒヨコはプレイ領域の下端寄り
- A〜Dボタンはキャンバス外の操作パネルに配置

## 操作

- 画面を指でなぞる：妖精を高速移動
- A：ウィンドカッター。空中の鳥を追い払う
- B：エアーブラスト。地上の敵や小枝を吹き飛ばす
- C：ウォーターボム。穴に植物の橋を育てる
- D：ヒヨコを短時間シールド

PCでは矢印キー、A〜Dキーでも操作できます。

## 起動

`index.html` をブラウザで開いてください。GitHub Pagesにもそのまま配置できます。
