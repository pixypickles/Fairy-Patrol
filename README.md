# Fairy Guardian Prototype v2.12

スマートフォン向け、縦長・見下ろし型のヒヨコ護衛プロトタイプです。

## v2.12 の変更

- 「風・下」「水・下」を削除しました。
- 下段ボタンを「ヒヨコ左」「ヒヨコ右」に変更しました。押している間、ヒヨコを左右へ誘導できます。
- 小川の左・中央・右に双葉を復活させました。
- 双葉へ前方ウォーターボールを当てると、その位置に草の橋が育ちます。
- ヒヨコは自動で橋へ向かわず、左右ボタンで完成した橋へ合わせて通します。
- 横幅いっぱいの段差には左・中央・右の3候補があり、そのうちランダムな1か所だけにひびがあります。
- ひびの位置へ前方エアーブラストを当てると通路が削れます。
- 段差もヒヨコを左右へ誘導し、削った通路から通します。

## 操作

- 円形スティック：妖精を8方向へ移動
- 風・上：前方エアーブラスト
- 水・上：前方ウォーターボール
- ヒヨコ左／右：押している間、ヒヨコを左右へ誘導

PCでは矢印キーで妖精、Aで風、Cで水、B/Dでヒヨコを左右へ誘導できます。


## v2.13 changes
- 川の双葉は左・中央・右の候補から毎回1〜2本だけ出現します。
- 段差の削れる切れ目も毎回1〜2か所だけ出現します。
- ヒヨコ左／右は1回押すごとの段階誘導です。左・中央・右の3位置を一段ずつ移ります。
- ヒヨコは少し間を置き、揺らぎながら自然に誘導方向へ寄ります。
