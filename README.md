# Fairy Guardian Prototype v2

現在までに固まった仕様を基に、継ぎ足しではなく一から作り直したHTML5 Canvas版です。

## 起動
`index.html` をスマホまたはPCのブラウザで開いてください。
GitHub Pagesにもそのまま配置できます。

## 操作
- 円形スティック：8方向移動
- 風・上：前方エアーブラスト
- 風・下：近距離・下方エアーブラスト
- 水・上：前方へ飛びながら落下するウォーターボール
- 水・下：真下へ短く落下するウォーターボール
- PC：矢印キー、A/B/C/D

## 主な仕様
- 縦長・完全見下ろし視点
- 中央の道なし、全面草原
- 気まぐれに動くヒヨコ1匹
- プラス点とマイナス点を別集計
- マイナスが増えてもゲームオーバーなし
- 鳥、キツネ、ネコ、ヘビ
- 小枝、段差、水辺、双葉から育つ植物橋
- 妖精は半透明の虹色4枚羽
