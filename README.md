# Fairy Guardian v3.0.7

GitHub Pages向けの縦長HTML5 Canvasゲームです。

## 今回の更新

- 地上の動物として、可愛い茶トラ猫を1匹ずつ追加
- 猫は2コマ風の足運びと尻尾の動きで、ゆっくりヒヨコへ近づきます
- 風または水が当たると驚いて画面外へ逃げ帰ります
- 猫の撃退はプラス60点、ヒヨコへ接近するとマイナス30点
- 鳥と猫が同時に押し寄せない、ゆるい出現ペースを維持
- 風の通常射程と長押しチャージはv3.0.6の仕様を維持

## GitHub Pagesでの使い方

最も確実なのは `single-file.html` を `index.html` に名前変更し、リポジトリ直下へ置く方法です。
複数ファイル版を使う場合は `index.html`、`css/`、`js/` を同じ階層に置いてください。
