# Fairy Guardian Prototype v2.5

スマートフォン向け・縦長見下ろし型の、ゆるくほのぼのしたヒヨコ護衛ゲーム試作です。

## v2.5 変更点

- ウォーターボールを濃い青色の丸い水球に変更
- 水球に透明感、白い反射、青い濃淡を追加
- ヘビの頭を大きくデフォルメし、丸い目と笑顔を強調
- 鳥を青・黄色・紫・桃色・緑を使ったカラフルな配色に変更
- 鳥、ヘビ、キツネ、ネコは攻撃を受けると倒れず、驚いて画面外へ逃げる
- 撃退時の「！」リアクションを追加

## 起動方法

`index.html` をスマートフォンまたはPCのブラウザで開いてください。
GitHub Pagesにもそのまま配置できます。
