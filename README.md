# Fairy Guardian Prototype v2.2

ブラウザで `index.html` を開いて遊べる、縦型・見下ろし護衛シューティングの試作です。

## v2.2 の変更
- 魔法弾と炸裂エフェクトの黒い輪郭を削除
- 鳥、キツネ、ネコ、ヘビに3コマ相当の簡易アニメーションを追加
- ヘビを長いS字の胴体、頭、目、舌、鱗模様で描き直し
- 小枝、段差、水辺、双葉と植物橋を大型化して描写を詳細化
- 草地に色むら、草の房、花、小石を追加し、少し自然な質感へ変更

## 操作
- 円形スティック：8方向移動
- 風・上：前方エアーブラスト
- 風・下：近距離エアーブラスト
- 水・上：前方ウォーターボール
- 水・下：真下ウォーターボール
