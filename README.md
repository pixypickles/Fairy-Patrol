# Fairy Guardian v3.0.5

小さな更新として、カラフルで可愛い鳥を追加しました。

- 鳥は一度に基本1羽だけ登場します。
- 羽ばたきは3段階に見える滑らかなアニメーションです。
- 風または水の魔法が直接当たるか、炸裂に巻き込まれると驚いて上空へ逃げ帰ります。
- 撃退するとプラス50点です。
- ヒヨコへ近づきすぎた場合はマイナス25点ですが、ゲームオーバーにはなりません。
- 妖精・ヒヨコ・草原・既存の魔法表現はv3.0.4を維持しています。

GitHub Pagesでは `single-file.html` を `index.html` に名前変更して置く方法が最も簡単です。
