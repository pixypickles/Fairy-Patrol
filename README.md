# Fairy Guardian v3.4.2 — 草原ブラッシュアップ

画像素材は使わず、Canvas と JavaScript の描画のみで更新しています。

- ヒヨコの左右移動を急な横滑りから、少し丸い軌道へ調整
- 花を1・3・5輪の小さな群生にし、白・黄・青を追加
- タンポポが小さくまとまって生えることがある配置へ変更
- 草原の色むらと草の密度を増やし、単純なパターン感を軽減
- 頭上の枝の影を薄く遠くへ移し、葉に細かな揺れを追加
- 岩を角張った多角形から丸みのある形へ変更
- 蝶が咲いた花へ近づき、短く止まる仕草を追加
- v3.4.1 の効果音・操作・地形ギミックは維持

GitHub Pages では `index.html` をそのまま置き換えてください。
